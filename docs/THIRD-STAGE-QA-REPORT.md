## 四、验收中发现并修复的真实缺陷

T7 不是走过场——以下 5 个缺陷是本轮验收发现的,发现前它们都已经在产物里。

### 1. 16 个品牌页在移动端横向溢出(严重)

`components.css` 给 `table` 设了全局 `min-width:760px`,而品牌页规格表所在的 `.table-shell .panel-in` 只有 `padding:0`,**没有 overflow**。结果 360px 下 16 个品牌页整页被撑破。

此前修的是 markdown 表格(rehype 包裹插件),组件内手写的表格是同一类 bug 的漏网之鱼。

修复:`.table-shell .panel-in{overflow-x:auto}`,并给容器加 `tabindex="0"` + `role="region"` + aria-label,保证纯键盘用户也能看到溢出列。

### 2. 年付折算价被写成「月费」(违反用户明确规则)

三处正文把 7 元(年付折算)写进了月费口径:

- `pillars/how-to-choose-airport.md`:「后者买 7 元 50GB 的套餐」与「25 元 150GB」并列
- `compare/value-calculation.md` 两处:「**月费 7 元**到 25 元」,其中一处直接喂给单价计算
- `compare/cheap-airport-truth.md`:「月费 7 元到 25 元」

讽刺的是,本站另有一篇文章专门论证「把 7 元和 14.9 元并列,读者会得出错误结论」。规则写了,自己却犯了。

全部改为标价口径并显式点出年付折算,`value-calculation.md` 里加了「这里刻意不写『月费 7 元』」的说明。

### 3. 禁用拓扑标签进入正文

`protocols/dedicated-line-worth-it.md` 的对比表把「运营商独立电路,**不经公网**」当事实陈述,同行还写了「晚高峰表现:**基本不受影响**」。前者在 T6 红线 4 的禁用标签列表里,后者是无法验证的绝对化断言。

改为「运营商采购的独立电路,不与公网国际出口共享带宽」与「受公网拥堵影响小,但仍取决于实际采购容量与售卖人数」,保留教学价值,去掉断言。同段「专线是『不排队』」也补上了「前提是这条路本身没被超卖」。

### 4. 品牌库按标价排序把两种口径混排,无任何警示

选「入门价格(低→高)」时,飞猫云 7 元(年付折算)排在唯兔云 14.9 元(月付)前面,制造「最便宜的是它」的印象。卡片各自标了口径是诚实的,但**排序这个动作本身**会盖过卡片上的小字。

修复:选项文案改为「标价数字(低→高,两种口径混排)」,并在该排序激活时显示口径警示,切走即隐藏。默认排序仍是可比的「单位流量成本」。

### 5. 三处品牌声明层数据与新品牌清单不符

对照用户提供的新品牌清单逐条核对 AI / 流媒体声明:

| 品牌   | 清单原文                                  | 修正前   | 修正后     |
| ------ | ----------------------------------------- | -------- | ---------- |
| 速界   | 「流媒体支持:当前资料**重点不在流媒体**」 | 声明覆盖 | 未说明     |
| U1S1   | 「可用于常见海外网络及 **AI 使用场景**」  | 未说明   | 声明覆盖   |
| 二猫云 | 两项均「显示**支持相关使用场景**」        | 均未说明 | 均声明覆盖 |

速界那条最严重:把厂商明说「没主打」渲染成了「声明覆盖该场景」。

### 附:一个门禁自身的缺陷

`pnpm format` 会把过长的单行 flow 序列(`relatedSlugs: ['a','b','c']`)折成多行 flow,而按行扫描 frontmatter 的门禁脚本只认块状序列,于是 **32 篇文章被误判为「内链少于 2 条」——内容一个字没动**。

修复不是放宽门禁,而是消除歧义:143 个 markdown 的 frontmatter 统一为块状序列(84 个文件被改写,prettier 不会重排块状序列,已验证幂等),并新增 4 条测试把这个不变量钉死,附带修复指引 `pnpm fix:frontmatter`。
