## 归属原则

品牌名、官网、注册、套餐、价格、优惠码、怎么样、稳定性、安全性这些**同意图词全部归属品牌主页面**,
不拆成多个页面互抢。主词统一取「<品牌>怎么样」——品牌查询里意图最明确、承接面最宽的一个。

以下查询**不单独建页**,在品牌页内消化:

| 查询类型   | 页面内落点                        |
| ---------- | --------------------------------- |
| 跑路风险   | 风险与状态区块 + FAQ              |
| 安全性     | 风险与状态区块                    |
| 退款       | 风险与状态区块的客服与退款入口    |
| 注册流程   | 优惠与注册区块                    |
| 套餐价格   | 快速事实 + 规格表                 |
| 客户端支持 | 客户端与协议区块,并内链到对应教程 |

理由(指令 T3.5):品牌故障 / 跑路 / 风险类查询没有独立于品牌页的搜索意图,
而且本站没有任何一家的运营异常事实可以支撑独立页面。凭空建页就是薄内容。
