买机场这件事,失败点很少出现在「不会付款」上,更多出现在付款之前的十分钟和付款之后的十分钟。前十分钟决定你有没有进错站、有没有把套餐字段读全;后十分钟决定问题被发现在还能追回的时间窗内,还是几天后才被察觉。

这篇只处理交易本身:怎么确认你正在打款的对象、套餐页上哪些字段真正决定可用量、付款出岔子时的处理顺序,以及一份必须当场跑完的验收清单。至于买哪一家,那是[逐家评测](/reviews/)和[对比栏目](/compare/how-to-choose-airport/value-calculation/)的事,本文不涉及任何具体服务商。

先把要确认的七项放在一起,它们构成下单前的门槛:

| 序号 | 确认项             | 没确认清楚的后果                      |
| ---- | ------------------ | ------------------------------------- |
| 1    | 官网地址可核验     | 钱付给了钓鱼站,账号与支付信息一并暴露 |
| 2    | 流量额度与倍率规则 | 标称 100G 实际只够用三分之一          |
| 3    | 同时在线设备数     | 家里三台设备互相顶掉线                |
| 4    | 限速阈值与触发条件 | 高峰期速度被压到不可用                |
| 5    | 支持的客户端与协议 | 手上的软件解析不出一半节点            |
| 6    | 退款与试用政策     | 不合用也拿不回钱                      |
| 7    | 客服渠道与响应方式 | 出问题时找不到人                      |

## 为什么先学会辨认官网,比先比价更重要?

因为比价选错只是多花几十块,进错站是把钱和账号一起交出去。仿冒站点的做法很成熟:域名与真站只差一个字母或一个后缀,页面整套克隆,连套餐价格都照抄,唯独收款账户是自己的。

可核验的入口有这些特征:域名能在多个独立来源(官方社交账号、长期存在的介绍页、你自己上次的浏览器书签)交叉对上;页面使用 HTTPS 且证书域名与地址栏一致;不通过聊天群里的短链接或搜索页推广位跳转。

> 首次访问就把官网加入书签,以后只从书签进入。搜索引擎结果页的排序会变,聊天记录里的链接会被替换,书签不会。仿冒站的具体识别方法在[假冒官网的辨认要点](/risk/fake-official-site/)里有更完整的列举。

## 套餐页上哪些字段决定了你实际能用到多少?

套餐页最醒目的两个数字通常是月费和流量,而这两个都不是决定性的。真正决定可用量的字段常常排在页面下方,或者写在服务条款里。

- **流量计费方式**:是按月重置,还是买断后用完为止;重置日是自然月 1 号还是购买日对应日。
- **节点倍率规则**:不同线路扣除的流量倍数不同,这一项经常只在节点名或帮助文档里出现,不在套餐卡片上。
- **同时在线设备数**:上限是几台,超出时是排队、掉线还是直接封禁。
- **限速策略**:是否有峰值带宽上限,是否在用量超过某个比例后降速。
- **协议与客户端支持**:提供哪些协议、给不给多种格式的订阅链接。
- **到期后的处理**:过期是暂停还是删除账户,补费能否恢复原节点。

## 流量、倍率、设备数、限速:四个数字怎么一起看?

单看任何一个都会得出错误结论,它们必须相乘或相约束着看。倍率把标称流量折小,设备数把可用量分摊,限速则决定同样的流量能在多长时间里花出去。

举一个纯示例的算法演示,数字均为假设值,不代表任何具体服务商:

```text
标称流量        100 GB / 月
常用节点倍率    2.0 倍
折后可用        100 ÷ 2.0 = 50 GB
家庭设备数      3 台共用
人均可用        50 ÷ 3 ≈ 16.7 GB / 人 / 月
```

如果这三台设备里有一台经常看在线视频,按常见码率推算,1080p 视频每小时大致消耗数 GB 级别的流量(不同平台与画质差异很大,这里只作量级参考),16.7GB 的人均额度会消耗得比预期快得多。把这四个数字放进同一个算式,才能判断套餐是否够用。更完整的单价换算方法写在[把套餐折成每 GB 实际单价](/compare/how-to-choose-airport/value-calculation/)。

## 试用和退款政策要看清哪几句话?

条款里真正起作用的往往是三句话,其余是铺垫:

| 要找的条款   | 常见写法                           | 你要确认的点                 |
| ------------ | ---------------------------------- | ---------------------------- |
| 退款窗口期   | 「购买后 X 小时/天内」             | 从付款成功算起还是从开通算起 |
| 流量使用限制 | 「已用流量不超过 X% 或 X GB」      | 验收测试本身会不会耗掉资格   |
| 排除情形     | 「优惠价、活动套餐、加油包不参与」 | 你买的那一档是否在排除名单里 |

第二条最容易踩:有些政策规定已用流量超过某个额度即失去退款资格,而你为了验收连了几个节点、跑了几次测速,可能已经越过门槛。稳妥做法是先做轻量验收(能拉订阅、能打开一个网页),确认基本可用后再做大流量测试。

> 条款以你下单当天页面上的文字为准,截图保存。事后条款页面被修改是常见情况,而截图是你唯一能拿出来的依据。

## 付款方式与订单状态异常时,先做什么?

先停手,不要重复下单。重复支付会产生第二笔订单,而多数服务商的退款流程比开通流程慢得多,你会用几天时间去追回本可以避免的一笔钱。

按这个顺序处理:

1. **刷新用户后台的订单页**,确认订单状态是「待支付」「已支付未开通」还是「已完成」。三种状态对应的责任方完全不同。
2. **查支付渠道的扣款记录**,确认钱到底出没出去。有扣款记录但订单显示未支付,属于回调延迟或丢失,这类问题只能由服务商在后台手动核销。
3. **截图订单号、支付时间、支付渠道流水号**,这三样是工单里唯一有用的信息,「我付了钱但没开通」不构成可处理的工单。
4. **提交工单并保留提交时间**,同时记下承诺的响应时限。

## 付款后十分钟内必须完成的三项验收

开通成功不等于可用。这三项要连着做完,顺序不能换,因为后一项依赖前一项成立:

1. **订阅能拉回节点列表**。在客户端里导入订阅并手动更新一次,看列表是否有节点、数量与套餐说明是否大致对得上。这一步验证的是账户状态和订阅接口,失败说明问题在服务端而不在你。
2. **节点能连通**。选两三个不同地区的节点分别连接一次,看握手是否成功。这一步验证的是节点可达性,全部失败要立刻反馈,而不是自己反复换客户端。
3. **目标网站能打开**。用你实际要用的那个服务测一次——要看视频就打开视频站,要用 AI 工具就打开对应页面。这一步验证的是出口 IP 在你的目标场景下是否可用,握手成功但目标站打不开属于另一类问题。

三项都通过,再去做大流量测速和长时间使用。任一项失败,当场提交工单,把「什么时候、哪个节点、什么现象」写清楚。相关的判断方法可以参考[订阅更新失败的定位](/troubleshooting/connection-failed/subscription-update-failed/)和[节点全部超时的排查](/troubleshooting/connection-failed/nodes-all-timeout/)。

## 开通失败或订单显示未支付,正确的处理顺序是什么?

处理顺序的原则是:先固定证据,再联系人工,最后才考虑退款或改用其他支付方式。

| 现象                        | 第一动作                          | 不要做的事         |
| --------------------------- | --------------------------------- | ------------------ |
| 已扣款,订单显示未支付       | 截图流水号后提交工单              | 再付一次           |
| 订单已完成,但后台无订阅链接 | 退出重新登录后台再看一次          | 立即注册新账号重买 |
| 订阅链接存在但返回空列表    | 换一个客户端再拉一次,排除 UA 问题 | 反复点更新         |
| 工单超过承诺时限无响应      | 按渠道升级并保留全部记录          | 在群里刷屏催促     |

关于订阅链接为什么会返回空列表、客户端标识如何影响服务端返回内容,机制部分写在[订阅、节点与客户端各管一段](/basics/subscription-and-node/)。

## 第一次购买,为什么建议先买短周期?

因为首次购买时你手里缺两样信息:自己的真实月用量,以及这家服务在你所在网络环境下的实际表现。这两样都只能用时间换,而年付相当于在没有这两个数据的情况下,把十二个月的钱一次性押上。

短周期的代价是单价高一些,换来的是低成本的退出权。观察满一个完整周期,重点看晚高峰是否可用、公告是否及时、工单是否有人回,再决定要不要延长。付费周期与风险敞口的关系,展开在[月付还是年付的决策方法](/compare/how-to-choose-airport/monthly-vs-yearly/)。

> 促销页面上的年付折扣通常在下个促销期还会出现。用「错过一次优惠」换「避免一次押错」,长期看是划算的。

## 小结

买机场的风险主要集中在两端:进站时认错门,和付款后没有当场验收。官网从书签进,套餐看流量、倍率、设备数、限速四个数字的乘积效果,退款条款截图留证。付款后十分钟内跑完拉订阅、连节点、开目标站三项验收,任一项不过就当场开工单。首次一律选最短周期,把判断留给下一个周期。
