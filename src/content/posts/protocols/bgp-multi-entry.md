有一个场景几乎每个人都遇到过:同一个账号、同一份订阅、同一个节点,在家里用得好好的,出差到另一个城市就开始卡,回酒店换成手机流量又好了一点。节点没变,落地服务器没变,协议也没变。变的是你到那台入口机的第一段路。

链路可以拆成三段,前面两篇分别讲了中间的跨境段和末端的出口 IP。这一篇补上最前面那一段:你的设备第一跳到底连到了哪里,以及这台机器和你的运营商之间是怎么互联的。

这一段的特殊之处在于,它是唯一一段随你的物理位置和运营商改变的。落地服务器对全国用户是一样的,入口不是。这解释了为什么同一家机场在不同人嘴里评价能差那么远。

## 入口、中间段和落地分别决定了什么

| 路段                | 谁在这一段起决定作用        | 出问题的表现                 | 你能做的调整     |
| ------------------- | --------------------------- | ---------------------------- | ---------------- |
| 接入段:设备到入口机 | 你的运营商 + 入口机互联方式 | 基线延迟高、换地点体验变化大 | 换入口、换运营商 |
| 跨境段:入口到落地   | 机场采购的线路等级          | 晚高峰劣化、丢包             | 换节点档位       |
| 出口段:落地到目标站 | 落地机负载 + 出口 IP 属性   | 速度波动、平台判定异常       | 换落地节点       |

三段的故障表现不重叠,这是分离问题的关键。接入段的问题有一个独特指纹:**换地点或换运营商就会变,换节点却几乎没用。** 如果你把同一机场的十几个节点全试一遍,延迟基线整体都偏高,那大概率不是节点的事,而是第一跳就绕远了。

## 多入口和单入口的体验差别体现在哪里

单入口的机场只有一台(或一组同址的)接入机器,全国用户都往那里连。对住得近、运营商互联好的人,这没有任何问题;对另一些人,第一跳就要跨半个国家。

| 对比项           | 单入口                 | 多入口                  |
| ---------------- | ---------------------- | ----------------------- |
| 第一跳距离       | 全国用户同一个目标     | 就近分配                |
| 换城市后的波动   | 明显                   | 较小                    |
| 入口故障时的影响 | 全员中断               | 可切到其他入口          |
| 不同运营商的差异 | 取决于那一台的接入方式 | 可按运营商分流          |
| 成本             | 低                     | 高,每台入口都要持续付费 |
| 常见规模         | 小型机场               | 中大型机场              |

倒数第二行是重点:多入口是持续成本,不是一次性投入。每台入口机都要按带宽付费,所以它通常出现在价格中上的套餐里,并且是机场愿意反复宣传的卖点。

## BGP 接入怎么影响三网用户的连接质量

先解释这个词。BGP 是互联网上各个网络之间用来交换路由信息的协议,一台"BGP 接入"的服务器同时连接多家运营商,由路由协议动态选择从哪一家进出。相对的是单线接入——机器只接一家运营商,其他运营商的用户想访问它,必须先绕到互联互通点。

那个"绕"就是延迟的来源。三家运营商之间的互联带宽有限,高峰期排队严重,所以单线入口对非本网用户的表现常常差出数倍。

| 接入方式  | 本网用户 | 跨网用户                  | 典型适用             |
| --------- | -------- | ------------------------- | -------------------- |
| 单线接入  | 好       | 需绕互联点,高峰期明显劣化 | 成本敏感的小规模部署 |
| 双线/多线 | 好       | 较好,按来源分流           | 中等规模             |
| BGP 多线  | 好       | 好,由路由协议动态选路     | 需要覆盖三网的服务   |

所谓"三网优化",在接入这一层指的就是让移动、电信、联通用户都能走到相对短的路径,通常靠 BGP 多线或按运营商分设入口实现。它不承诺跨境段的质量——那属于另一段的事,见[中转与直连的路段拆解](/protocols/how-to-choose/transit-vs-direct/)。

## 智能接入这个说法,实际指的是什么

宣传里的"智能接入""智能选路",落到运营层面通常是下面几种之一:

| 宣传说法     | 常见的实际实现                 | 对你的意义                |
| ------------ | ------------------------------ | ------------------------- |
| 智能选路     | 域名解析按来源返回不同入口地址 | 有效,但切换粒度较粗       |
| 自动就近接入 | 由客户端测速后选延迟最低的入口 | 有效,依赖客户端支持       |
| 智能负载     | 把用户按比例分配到多台入口     | 主要是分担负载,不一定更快 |
| 智能加速     | 无明确技术含义                 | 当作营销词看待            |

前两种是真的在按你的位置做选择,后两种更多是资源调度。区分它们的办法很朴素:如果你在两个不同城市连同一个节点,拿到的入口地址不同,说明确实做了来源分流;如果全国拿到的都是同一个地址,那"智能"发生在别处。

> 机场公开资料里的接入描述属于厂商声明,没有第三方核验机制。它可以作为筛选线索,判断仍要以你自己在实际使用地点测出的延迟为准。

## 为什么换个城市或换个运营商,体验就变了

因为你只改变了三段中的第一段,而这一段恰好是唯一与你位置强相关的。

具体机制有三层。地理距离改变了物理传播时间,这一层通常只有几毫秒到几十毫秒。运营商改变了路由路径,同城不同运营商到同一台入口机的跳数可以差很多。最后是本地接入网的拥塞情况,校园网、酒店网络和公司网络的出网质量与家庭宽带完全不是一回事。

三层叠加起来,同一个节点在两个地点的基线延迟差出一倍是很常见的。判断方法很直接:在两个地点分别 ping 同一个节点,如果差值主要体现在基线而不是抖动上,那就是接入段的路径变了。

## 移动、电信、联通用户各自要重点看什么

三家的接入特征不同,关注点也应该不同:

| 运营商           | 接入段的常见特征            | 优先确认的事             |
| ---------------- | --------------------------- | ------------------------ |
| 电信             | 用户基数大,入口机常优先适配 | 晚高峰的跨境段而非接入段 |
| 联通             | 出境路径通常较短            | 入口是否为本网或多线     |
| 移动             | 用户量大,跨网互联压力明显   | 入口是否覆盖移动线路     |
| 广电及虚拟运营商 | 底层借用其他运营商网络      | 实测为准,标称参考价值低  |

不要照搬别人的结论。同一家机场在不同运营商用户口中评价相反,大多数时候不是谁在说谎,而是他们走的接入路径根本不同。

## 怎么判断一家机场是不是真做了多入口

四个可以自己做的检查,按可操作性排列:

1. **看订阅里的服务器地址是否多样。** 把节点配置展开,如果几十个节点指向的入口地址高度集中在一两个,那入口层大概率是单点。
2. **在两个不同网络下取同一节点的地址。** 家庭宽带和手机流量各连一次,对比解析到的地址是否相同。不同,说明做了来源分流。
3. **比较基线延迟与物理下限。** 到入口的延迟明显低于你所在城市到该地区的常规水平,说明入口离你很近。
4. **看故障时的表现。** 出过问题的机场里,单入口的典型症状是全部节点同时不可用;多入口更常见的是部分用户受影响。

前两项一次就能做完,后两项需要一点时间积累。如果四项里有三项指向单点,那么无论宣传里写了什么,把它当单入口来评估更稳妥。相关的核验思路,[线路真实性的自查方法](/protocols/how-to-choose/verify-line-and-ip/)那篇还有更完整的展开。

至于测出来的延迟差异该归给哪一段,可以对照[速度归因的排查顺序](/protocols/how-to-choose/protocol-speed-myth/):先排落地负载,再排跨境段,最后才轮到接入段和协议。

## 小结

入口是链路三段里最容易被忽略、却唯一随你的位置改变的一段。多入口的价值不在于"节点更多",而在于让不同城市、不同运营商的用户都能就近落到一台接入机上。BGP 接入解决的是跨网绕路的问题,它属于接入层,不承诺跨境段质量,两者不要混谈。宣传里的"智能接入"有真有假,用两个不同网络各取一次入口地址就能大致分辨。判断一家机场是否真做了多入口,看入口地址的集中度比看宣传页有用得多。
