在 App Store 搜索框里输入 Shadowrocket 或者「小火箭」,返回的却是一堆加速器、清理工具和不相干的游戏——几乎每个 iOS 用户第一次找它都会遇到这一幕。这不是它被下架,也不是名字打错了。App Store 按账号所属地区分区上架,开发者没有在中国大陆区提供这款应用,于是中国区账号从搜索结果到榜单都看不到它。

所以「下载小火箭」这句话里其实藏着两个动作:让自己的 App Store 处在一个海外地区,再完成一笔付费购买。真正卡住人的往往是第二个动作,而不是网络。

还有一类更麻烦的情况:在搜索引擎里搜「小火箭下载」,排在前面的常常是提供 IPA 安装包、安卓 APK 或者「免费版」的第三方站点。这些东西和 App Store 里那款付费应用没有任何继承关系,后文会专门说明为什么不能碰。

## 为什么中国区 App Store 里搜不到它?

App Store 的可见性由账号的**账单地区**决定,而不是由手机所在位置或当前连的哪个 Wi-Fi 决定。开发者上架时可以逐地区勾选,不勾选的地区就完全检索不到,连直接打开商店链接也只会提示该项目在当前商店不可用。

这带来一个常见误解:很多人以为「先连上代理再搜就能搜到」。实际上换网络不改变账号地区,搜索结果不会有任何变化。判断依据只有一个——打开「设置 → Apple 账户 → 媒体与购买项目」,看账号地区写的是哪里。

> 换区只需要在 App Store 内切换登录账号,不要在「设置」顶部退出 iCloud。后者会影响照片、备忘录、查找和备份,属于完全不同的账号层级。

## 怎么确认自己看到的是正版?

海外区商店里同样有蹭名字和图标的应用。核对时看这几处,比只看名字可靠:

| 核对项     | 正版的表现                     | 需要警惕的表现                         |
| ---------- | ------------------------------ | -------------------------------------- |
| 分发位置   | 只出现在 App Store 商店页      | 网页提供 IPA、需要「信任企业证书」     |
| 计费方式   | 明码标价的一次性付费应用       | 标注免费下载却强制订阅,或引导站外收款  |
| 开发者名称 | 商店页开发者一栏与官方公布一致 | 开发者名与图标风格拼凑、评论区语言杂乱 |
| 宣传口径   | 工具类应用,不承诺任何线路      | 宣称「一键翻墙」「内置免费节点」       |

最后一行尤其值得强调:这类客户端本身不附带任何线路,凡是宣称装上就能直接上网的,基本可以判定不是它。

## 一次性买断到底是什么意思?

它属于买断制付费应用——付一次钱,权限写进 Apple ID 的「已购项目」,之后的版本更新不再额外收费。App Store 页面上的标价随地区和汇率浮动,长期处在几美元的区间,具体数额以你所在商店当前显示的价格为准。

需要区分的是,买断针对的是软件本身,不包含任何网络服务。机场的月费、流量套餐是另一笔开销,两者没有捆绑关系。有人以为买了 App 就等于买了线路,装好后发现节点列表空空如也,误会就出在这里。

## 换新手机、多设备,还要再买吗?

判断标准只有一条:是不是同一个 Apple ID。

| 场景                           | 是否需要再次付费 | 说明                                                       |
| ------------------------------ | ---------------- | ---------------------------------------------------------- |
| 换新 iPhone,仍用原购买账号     | 否               | 在 App Store 的「已购项目」里重新下载                      |
| 家人的 iPhone,登录同一购买账号 | 否               | 但该设备会与这个账号产生关联记录                           |
| 家人用自己的 Apple ID          | 是               | 除非通过家人共享,且该应用支持共享                          |
| 从 iPhone 装到 iPad            | 否               | 同账号下可安装,界面按设备适配                              |
| Apple 芯片的 Mac               | 视商店而定       | 部分 iOS 应用允许装在 Mac 上,以商店页是否提供 Mac 版本为准 |

换机之后最容易被忽略的一点:App 装回来了,里面的订阅和规则并不会自动跟过来。系统备份恢复能带回一部分本地配置,但订阅地址通常需要重新导入一次。

## 网上的「安卓小火箭」「免费版」是什么东西?

三类东西经常顶着这个名字出现,性质各不相同:

1. **同名安卓应用**——套用名称和火箭图标,内核与原作无关,权限申请往往过度。
2. **破解 IPA 或企业签名包**——需要安装描述文件、信任证书,签名随时可能被吊销,应用会毫无征兆地打不开。
3. **所谓「免费版」网页工具**——通常把流量转发到不明服务器上,你的全部请求都经过对方。

代理客户端的特殊性在于,它天然拥有接管全部网络流量的权限。一个被改动过的客户端能做的事情远超普通 App:静默转发流量、回传订阅地址、注入额外规则。订阅地址一旦泄露,相当于把你付费买来的账号交给了别人,而机场那边看到的只是同一份订阅在多地登录。想系统了解这类风险的成因,[风险预警栏目](/risk/) 里有更完整的讨论;对「免费」两个字背后的代价存疑的话,[免费节点栏目](/free-nodes/) 也值得先读一遍。

> 判断标准可以简化成一句话:凡是绕开 App Store 的安装方式,都不要用在代理客户端上。省下的那几美元,和一份被转卖的订阅相比不成比例。

## 装完之后还差什么?

打开 App,你会看到一个空白的节点列表和一个未连接的开关。此时缺三样东西:一份来自机场的订阅链接、一次成功的导入、以及首次连接时系统弹出的 VPN 描述文件授权。

授权弹窗只在第一次连接时出现,点了「不允许」之后不会再主动弹出,表现为怎么点开关都连不上。遇到这种情况,可以到系统设置的「通用 → VPN 与设备管理」里检查配置是否存在。

订阅怎么拿、三种导入入口有什么差别、导入成功该看哪几个信号,写在 [Shadowrocket 导入订阅的三种方式](/guides/shadowrocket/shadowrocket-import-subscription/)。如果导入之后出现「显示已连接却打不开网页」,那属于另一类问题,可以直接跳到 [假连接状态的排查顺序](/guides/shadowrocket/shadowrocket-connected-no-internet/)。对整条路径还没有全局印象的话,[小火箭全流程专题](/guides/shadowrocket/) 把四个阶段的关系交代得更完整。

## 小结

中国区搜不到小火箭是上架策略造成的,不是故障,换网络没用,只能换账号地区。它是买断制付费应用,权限跟着 Apple ID 走,换设备重装不重复收费,但软件费用与机场服务费是两笔完全独立的开销。核对正版看分发位置、计费方式和开发者名称,凡是绕开 App Store 的安装包一律不用。装好之后 App 仍是空的,导入订阅才是让它真正能工作的下一步。
