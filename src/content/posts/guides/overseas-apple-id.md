小火箭在 App Store 里是一款付费应用,并且从未在中国大陆区上架过。这两件事叠在一起,导致大量人卡在了买软件之前的那一步:不是不会配置,而是根本搜不到它。搜索结果为空不代表被下架,只代表你当前登录的 App Store 账号地区不对。

这里要分清两个常被混为一谈的概念。**Apple ID 的地区**决定你能进哪个商店、看到哪些 App、用什么货币结算;**iCloud 里的数据**则是照片、通讯录、备份那一套,和商店地区没有绑定关系。iOS 允许这两者用不同账号——设置里的 iCloud 一栏保持原账号,App Store 一栏换成海外区账号,是完全受支持的用法,也是本文推荐的做法。

还有一点值得先说明:付费购买的记录是绑定在 Apple ID 上的,不是绑定在手机上。这意味着你只需要在某一个海外区账号上买一次,以后换几部 iPhone 都能用它重新下载。反过来,一旦这个账号丢了,已经付过的钱不会跟着你走。这一条决定了后面所有取舍。

## 改地区还是新建账号,两条路分别适合谁?

两种做法都能达到目的,差别在于牵动的东西多少。

| 对比项           | 把现有 Apple ID 改地区               | 新建一个海外区专用账号     |
| ---------------- | ------------------------------------ | -------------------------- |
| 前置条件         | 余额必须清零、订阅需先取消           | 只需一个未注册过的邮箱     |
| 影响范围         | 整个账号的商店、订阅、家庭共享一起变 | 只影响这个新账号           |
| 日常 App 更新    | 原地区独占的 App 可能无法更新        | 日常 App 不受任何影响      |
| 需要记住的账号数 | 一个                                 | 两个                       |
| 想改回去         | 需要再走一遍清余额流程               | 直接不用它即可             |
| 适合谁           | 账号很干净、不用国区订阅的人         | 绑着家庭共享、订阅较多的人 |

判断标准其实很简单:打开账号看一眼余额和订阅列表。有一分钱余额、或者有任何一个正在续费的订阅,改地区就必须先处理掉它们,这时新建账号反而更省事。

> 一个高频误解是「改地区会清空 iCloud」。不会。受影响的是商店侧的余额、订阅和部分 App 的可更新性,iCloud 照片与备份不因地区变更而删除。但反过来说,正因为它牵动的是订阅和付款关系,才建议账号越干净的人才走这条路。

## 海外区账号需要绑定什么付款方式才能付费购买?

注册海外区账号本身可以不填付款方式,但那样的账号只能下载免费 App,遇到付费应用会直接卡在结算页。要让它具备付费能力,常见有三条路。

| 付款方式                        | 是否需要境外卡 | 主要限制                       | 稳妥程度                 |
| ------------------------------- | -------------- | ------------------------------ | ------------------------ |
| 兑换对应地区的 App Store 充值码 | 否             | 充值码地区必须与账号地区一致   | 较高,一次性,不留支付信息 |
| 绑定该地区发行的银行卡          | 是             | 通常需要账单地址与卡片地区匹配 | 高,但门槛高              |
| 绑定第三方支付账户              | 视地区而定     | 支持范围随地区与政策变化       | 中等                     |

对绝大多数只想买一个几美元 App 的人,充值码是成本最低的一条:账号里留的是余额而不是支付凭证,买完就结束,不存在后续被扣款的可能。要提醒的是,充值码有明确的地区属性,美区码只能兑进美区账号,买错了既不能兑换也很难退。

至于软件本身的定价,以 App Store 页面上实时显示的金额为准,历史上它调整过若干次,任何文章里写死的数字都可能已经过期。

## 买来的「成品美区账号」为什么算高风险资产?

网上流通的「已购小火箭账号」大多是同一个账号被卖给了很多人。你付的钱买的不是所有权,而是一段不确定能维持多久的使用权。

需要清楚它可能怎么失效:

- **原持有者随时可以改密码。** 账号的邮箱和手机号都不在你手上,改密后你没有任何找回途径,申诉时也拿不出所有权证明。
- **多地同时登录容易触发安全审核。** 苹果要求二次验证时,验证码发到的是原持有者的设备,你只能等对方配合。
- **账号可能被直接锁定。** 一旦被判定为异常共享,整个账号连同里面的已购内容一起冻结。
- **你的日常数据可能被卷进去。** 如果图省事把这个来路不明的账号也登录进了 iCloud,风险就从「一个 App」扩大到了「你的照片和备份」。

> 更实际的一层考虑是:小火箭这类工具会随 iOS 更新迭代,更新时 App Store 会要求输入购买账号的密码。共享账号的密码随时可能变,于是你迟早会遇到「能用但永远更新不了」的状态。等到某次系统升级后旧版本不再兼容,那笔钱就白花了。

## 账号被锁定后,已经装好的小火箭还能用吗?

分两种情况,结论完全不同,这一点值得单独拎出来说清楚。

| 状态                        | 已装好的 App 能否继续运行 | 能否重新下载       | 能否更新             |
| --------------------------- | ------------------------- | ------------------ | -------------------- |
| 账号正常,只是切回了日常账号 | 能                        | 能(切回购买账号后) | 能(输入购买账号密码) |
| 账号被锁定或密码被改        | 能,直到你删掉它           | 不能               | 不能                 |
| 删除 App 后账号才失效       | 不适用                    | 不能               | 不适用               |

已安装的应用不会因为账号失效而被远程移除,它会继续躺在手机里正常工作。真正的分界线是**你有没有手动删掉它**——删掉那一刻,重新下载的通道就关上了。

所以一条很务实的建议:整理手机、清理存储空间的时候,把小火箭排除在外。很多人不是账号丢了才用不了,而是自己顺手删掉之后才发现装不回来。

## 为什么建议把「购买账号」和「日常 iCloud 账号」分开?

把两者分开的好处是把风险装进了盒子里。购买账号只承担一件事:证明这个 App 是买过的。它不存照片、不存备忘录、不做设备定位,即便哪天真的出问题,损失范围仅限于需要重新买一次 App。

具体到操作层面,iOS 的设置界面里这两栏是独立的:顶部头像进去的是 iCloud 账号,媒体与购买项目那一栏才是 App Store 账号。把后者换成海外区账号并不会让你退出 iCloud,查找、同步、备份都照常。

反过来,如果贪图省事把海外区账号直接登录进 iCloud,你会得到一个非常尴尬的局面:照片和通讯录同步到了一个你并不完全掌控的账号里。用的是自己注册的账号还好,用的是买来的共享账号则是明确不该做的事。

## 买完之后怎么把 App 装回日常使用的 iPhone?

购买和使用可以发生在不同时间、不同设备上,顺序如下:

1. 在任意一台 iOS 设备上,用海外区账号完成购买——这一步的产出是账号里的一条购买记录,与设备无关。
2. 回到日常使用的 iPhone,进入 App Store,把媒体与购买项目里的账号临时切换成购买账号。
3. 进入账号页的「已购买」列表,找到小火箭点云朵图标下载。这里下载不会重复扣费,因为购买记录已经存在。
4. 下载完成后立刻把 App Store 账号切回日常那一个,避免日常 App 的更新提示混进海外区账号。
5. 首次启动小火箭时,系统会弹窗请求添加 VPN 配置,允许一次即可,后续不再询问。

装好之后,下一步是把机场的订阅加进去。最快的方式是扫机场后台那张订阅二维码,顺序和注意事项写在 [Shadowrocket 二维码导入的正确顺序](/guides/shadowrocket/qr-code-import/) 里;节点导进去之后节点列表会不会自动跟着机场变,则由 [订阅刷新机制](/guides/shadowrocket/update-subscription/) 决定。整条配置路径的位置关系,可以回到 [小火箭全流程专题](/guides/shadowrocket/) 对照。

> 更新时反复弹出让你输入某个陌生 Apple ID 密码的提示,并不是中毒,而是这个 App 记得它是被谁买下的。想彻底摆脱这个提示,只能用当前日常账号重新买一次。

## 小结

小火箭的门槛一半在账号而不在软件。账号干净的人改地区最快,绑着订阅和家庭共享的人应该新建一个专用海外区账号,只在 App Store 那一栏切换,iCloud 保持不动。付费能力用对应地区的充值码解决最省心,不必绑境外卡。买来的共享账号看起来便宜,代价是随时可能失联,并且一旦被锁,已购内容无法再下载。装好之后不要顺手删掉它——删除那一刻,你才真正会失去它。
